## Decisions
- Game is 3D (user).
- First feature: a controllable spaceship. Feel is the user's job; the code gives a clear tuning interface (user).
- Ship model: hand made triangles in a C array (render_create_model), not a model file (user).
- Orientation: quaternions (user).
- Steering: two points, mouse moves an aim, the ship turns toward it through the flight model (user's idea, after a virtual stick and direct mouse both felt wrong).
- Chase camera behind and above; free camera on Backspace (user). Debug console later (user).
- Panel: grouped columns that fold, only feel numbers on it, linear sliders except max particles and rate /s (log), save and load, no reset (user). Since 2026-11-15 session 3: a side panel tree instead of columns, max particles code only, values can be typed, emitter colors in it (focus/engine.md, Panel and Decisions).
- Controls: Space boost, hold right mouse button drift, left click locks the mouse, Esc unlocks (user).
- Code defaults = the user's saved settings (pasted 2026-11-14). Before removing a panel control, put the user's saved value into the code default first (saves only load into controls on the panel; removing compare that way broke the feel once).
- Thrusters ramp up and down (thrust_response) with an engine cutoff, never run weaker (user).
- Exhaust: look only GPU particles (user). Sparks fly free once out: shoot speed + the ship's velocity at that moment, in world space (user, after trying sparks stuck to the ship). Rate, speed and cone come from each thruster's force share; speed has a base so sparks never come out slower than the ship drifts (user).

## Thruster particles
- Goal (user): an obscene amount of particles shooting out of the thrusters, using the GPU as much as possible, without costing the physics anything.
- Look only (user): gameplay never reads them (GPU readback is slow and late). Code goes in render/particles.c, not phys/.
- Plan: CPU sends emitter orders per frame (nozzle position, direction, firing share, ship velocity), compute shaders spawn and move, one draw reads the same storage buffer. CPU cost does not grow with the count.
- Ring buffer of fixed slots (no free list), age + lifetime per particle, dead ones skipped in the draw. Random spread from a hash of the slot. Spawns spread along the nozzle's path since last frame. Simulated per drawn frame with the real frame time, not the 1/60 physics step.
- Drawn as camera facing squares (can stretch along velocity), soft round glow in the shader, additive blend, depth TEST (hidden by solid things, never hides others), so no sorting. The real limit is overdraw (pixels painted over and over), so size matters more than count.
- Later: bloom (needs an offscreen scene texture).
- Step 1 bridge: DONE. Step 2 particle system: DONE. Step 3 thruster attachment: DONE (six nozzles, thrust share drives rate, speed, cone). Next: looks (user: looks bad, user says what).

### Particle code map (src/render/particles.c, shaders at the end of render/shaders.c)
- API (render.h): RenderEmitter (local, position, rotation, direction, velocity, rate, speed +- spread, cone, lifetime +- spread, size, color_start, color_end; memory = RenderEmitterMemory: previous_position, carry, started, anchor, render_emit's own). local = 1: sparks live in the emitter's space (an anchor: position + rotation sent every frame, up to 64, never given back), so they move and turn with it; velocity unused. local = 0: world sparks, a trail. The ship uses world sparks; local emitters are built but unused. render_emit(&emitter) once per frame, up to 16 per frame. render_particle_tuning: capacity (ring slots, up to 1048576), drag /s, stretch s. render_particle_estimate (rate * lifetime, at most capacity). render_begin now takes the frame seconds.
- Buffer: PARTICLE_MAX_SLOTS 1 << 20, 48 bytes each (position, age, velocity, lifetime, size, two packed colors), starts zeroed = dead. Ring head moves by spawn count, wraps at capacity.
- Uniform ParticleFrame: view_proj, eye (w frame seconds), camera right (w stretch) and up (w velocity kept this frame), capacity, head, spawn_total, emitter_count, seed, slot_count, 64 anchors (32 bytes: position, rotation xyzw), 16 emitters (96 bytes, anchor = 1 + index or 0). Header + all anchors + the used emitters are uploaded (2384 bytes with 2 emitters). Particle.anchor (the old pad): local particles keep position and velocity in anchor space, spawn turns the direction by the anchor's inverse, the draw turns them back into the world with the anchor's current position and rotation.
- render_end order: compute pass (move all PARTICLE_MAX_SLOTS slots, then spawn spawn_total threads), shadow pass, screen pass: meshes, lines, particles (4 corner strip x capacity instances, additive, GPU_DEPTH_TEST), 2D.
- Spawn: emitter found by first index, random from a PCG hash of (index ^ seed), even spread over the cone's cap, spread along previous -> position with matching age. Move: velocity *= kept share, position += velocity * seconds, age += seconds, dead slots read 8 bytes and stop.
- Draw: square facing the camera (camera right/up from the view projection rows), or a streak along the velocity (length size + speed * stretch) when it moves. Glow (1 - r^2)^2, color start -> end over life, fades out with life.
- Idle cost zero: particle_awake_seconds counts down from the longest lifetime emitted. At 0 no passes and no draw.
- 2026-11-15: nozzles are now engine emitters (focus/engine.md, Step 1): ship_emitter_types main / side, ship_emitters, panel groups main and side. The line below is the older description.
- Thruster attachment (ship.c): six thrusters (SHIP_THRUSTER_*, named after the push), eight nozzles (ship_nozzles[SHIP_NOZZLE_COUNT]: thruster, position + exhaust direction in ship axes). MAIN two engines on the back face (+-0.4, 0.03, 0.62) out the back, REVERSE two on the front edges either side of the nose (+-0.17, 0, -0.85) out the front, RIGHT on top of the left wing (-0.6, 0.09, 0.4) out left, LEFT on top of the right wing out right, UP keel (0, -0.25, 0.5) out the bottom, DOWN top ridge (0, 0.35, 0.45) out the top. ship_draw_exhaust (from hunter2_draw): each nozzle gets the ship_exhaust look, thrust share = its thruster's eased force now (from ship.thrust) / main thrust (1 = main at full, boost in it): rate = look rate * share / that thruster's nozzle count (two nozzles split the sparks), spark speed = base speed + (look speed - base speed) * share (ship_base_speed 30, slider base speed m/s), cone = look cone / (1 + cone squeeze * (share - 1)) (ship_cone_squeeze 0.3, slider) (user: rate, speed and cone sliders = main at full), placed and turned with the drawn ship, ship velocity on top. Off nozzles still call render_emit at rate 0 so their trail starts from the right spot. Nozzles below the engine cutoff fire nothing.
